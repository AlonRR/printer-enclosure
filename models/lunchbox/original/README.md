# The original LunchBox files

The remix builds on GekoPrime's **LunchBox**, which is not copied into this repository:
download it from its page, <https://www.printables.com/model/468166>, and put these files here:

| File | What it is |
|---|---|
| `filter_caddy_110x74x21.stl` | the body: the HEPA holder, the carbon bed, the channel to the fans |
| `filter_lid_110x74x21.stl` | the lid |
| `axial_fan_caddy_40x28.stl` | the fan section, for three 40 mm fans |
| `furnace_filter.stl` | the frame for cut HEPA paper (printed as it is; the remix does not change it) |

The insert, the gaskets and the blank build without them. The body, the lid and the fan section with
their tabs, the assembly pictures and `scripts/lunchbox-checks.py` need them, and fail loudly when one is
missing.
