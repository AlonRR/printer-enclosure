[project layout](https://github.com/AlonRR/scad-tools/blob/main/docs/project-layout.md) keeps each superseded
file at the path it had. The LunchBox is kept as a whole project in a folder of its own instead, laid out as
the repository was when it went, because its checks and its airflow case still run from there.
